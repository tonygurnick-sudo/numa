# Document Completeness App

This is the Proof of Concept (PoC) for the **Document Completeness App**, which allows users to upload documents, analyze their completeness, and perform gap analysis based on predefined requirements.

## Project Structure

- **app.py**: The main entry point for the Streamlit web application.
- **pyproject.toml**: Poetry configuration file, defining project dependencies and settings.
- **poetry.lock**: Lockfile generated by Poetry, ensuring consistent dependencies across environments.

## Features

1. **File Upload**: Upload documents (PDF, DOCX, TXT) via the web interface.
2. **S3 File Management**: Documents are uploaded to an S3 bucket for storage and processing.
3. **Document Analysis**: Documents are analyzed for completeness using AWS Textract and a custom Document Completeness Agent (DCA).
4. **Gap Analysis**: The system performs gap analysis and returns results to the user via the UI.

## Requirements

- **Python 3.12+**
- **Poetry** for dependency management

## Run the code
streamlit run .\document-completeness-app\app.py
