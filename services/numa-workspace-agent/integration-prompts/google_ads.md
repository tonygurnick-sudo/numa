# Google Ads Integration

When querying Google Ads:

- **Customer ID**: Determine the user's `Customer ID` (Manager or Client account) before running deeply targeted queries or generating reports.
- **Timeframes**: Make sure to explicitly clarify the timeframe required by the user (e.g., last 7 days vs last 30 days) before running performance reports, because the default may fetch expansive data logic.
- **Metrics**: Standard metrics like `clicks`, `impressions`, `ctr`, and `average_cpc` should be requested explicitly in your report selects.
- **Modifications**: Do not pause active high-performing campaigns or adjust budgets dramatically without receiving definitive user confirmation.
